# Синга Сервис — сайт сервисного центра (v11)

Доработанная версия статического сайта. Без сборщиков и фреймворков —
открывается прямой ссылкой на `index.html`.

> **v11 — Premium design upgrade.** Применён современный визуальный язык 2026:
> тёмный hero с радиальным glow, glassmorphism на карточках, soft tinted neutrals,
> кинетическая типографика, грейн-текстуры, поэтапные анимации появления карточек.
> Все правки скопом с `.design-v11` — старая база сохранена.
>
> **Критические фиксы:** убраны фейковые цифры «5,0 / 226 оценок / 79 отзывов»
> в hero и trust-proof; калькулятор `.opt` кнопки восстановили читаемые лейблы;
> favicon-paths переведены с root-absolute на relative для работы локально.
>
> Подробный аудит и список изменений — в `AUDIT.md`.

### Метрика и события
- В `<head>` каждой страницы — закомментированный блок Яндекс.Метрики:
  ```html
  <!-- YANDEX METRIKA COUNTER PLACEHOLDER -->
  <!-- <script>...</script> -->
  ```
  Раскомментируйте и замените `XXXXXXX` на свой counter id.
- В `script.js` готовая обвязка событий (вызывает `ym(id, 'reachGoal', name, payload)` если Метрика подключена):
  - `click_phone`, `click_telegram`, `open_route`, `open_modal`
  - `submit_lead`, `submit_lead_success`
  - `select_device`, `select_problem`, `select_address`
  - `scroll_50`, `scroll_75`, `scroll_90`
- Все кнопки звонка имеют `data-goal="click_phone"`, Telegram — `data-goal="click_telegram"`, маршруты — `data-goal="open_route"`. Цели срабатывают автоматически.
- Если счётчик не подключен — никаких ошибок, всё молча работает дальше.

### Технические правки
- `styles.css?v=4` и `script.js?v=4` — cache-busting.
- Адаптив проверен на 320 / 375 / 390 / 414 / 768 / 1024 / 1280 / 1440 / 1920 — везде без горизонтального скролла.
- Доступность: у всех `<input>` есть `<label>`, у кнопок — `aria-label` где нужно, фокус с клавиатуры виден через `:focus-visible`, у декоративных SVG — `aria-hidden`.
- Все внутренние ссылки рабочие (проверено: 0 битых).
- На каждой странице ровно один `<h1>`.

## Как открыть локально

1. Распакуйте архив.
2. Откройте `index.html` двойным щелчком в современном браузере.
3. Чтобы редактировать — открывайте HTML/CSS/JS в любом редакторе (VS Code, Sublime, Cursor).

> Совет: для разработки удобно поднять локальный сервер:
> `cd singa-service && python3 -m http.server 8000`, затем открыть http://localhost:8000

## Как залить на хостинг

Любой хостинг, поддерживающий статику:

- **Reg.ru / Beget / Timeweb / nic.ru:** залейте все файлы из папки `singa-service/` в `public_html/` или `www/` по FTP / SFTP. Главная — `index.html` — в корне.
- **Netlify / Vercel / Cloudflare Pages:** перетащите папку в личный кабинет; сайт развернётся за минуту. Можно подключить свой домен.
- **VPS с Nginx:** положите файлы в `/var/www/singa-service/` и пропишите `root /var/www/singa-service;` в конфиге.

После размещения:
1. Замените `https://singaservice.ru` на ваш реальный домен в:
   - `<link rel="canonical">` всех HTML (поиском по `singaservice.ru` — найдёте за минуту);
   - `<meta property="og:url">`;
   - `robots.txt`;
   - `sitemap.xml`;
2. Добавьте сайт в Яндекс.Вебмастер и Google Search Console.
3. Загрузите туда `sitemap.xml`.

## Как подключить Яндекс.Метрику

1. Создайте счётчик на [metrika.yandex.ru](https://metrika.yandex.ru/), получите его `counter_id` (число).
2. В каждом HTML-файле раскомментируйте блок после `<!-- YANDEX METRIKA COUNTER PLACEHOLDER -->`:
   ```html
   <script type="text/javascript">
   (function(m,e,t,r,i,k,a){...})(window,document,"script","https://mc.yandex.ru/metrika/tag.js","ym");
   ym(YANDEX_METRIKA_ID,"init",{clickmap:true,trackLinks:true,accurateTrackBounce:true,webvisor:true});
   </script>
   <noscript>...</noscript>
   <script>window.SINGA={ymCounter:null};</script>
   ```
3. Замените `XXXXXXX` (3 места: в `ym()`, в noscript URL и в `window.SINGA`) на ваш реальный counter id.
4. Готово. В Метрике в разделе «Цели» создайте цели с теми же названиями, что вызываются из JS: `click_phone`, `click_telegram`, `open_modal`, `submit_lead`, `submit_lead_success`, `select_device`, `select_address`, `open_route`, `scroll_50`, `scroll_75`, `scroll_90`. Все они уже отправляются автоматически.

## Как подключить безопасную отправку заявок (Telegram-бот)

### Вариант А — без сервера (быстро)
Ничего делать не нужно. Уже работает: пользователь жмёт «Отправить», видит «Спасибо», и ему предлагается продублировать заявку в Telegram кнопкой — открывается чат с подготовленным текстом. Заявка не теряется, но требует подтверждения от пользователя.

### Вариант Б — с сервером (рекомендуется для рекламы)
1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Получите ваш `chat_id` через [@userinfobot](https://t.me/userinfobot).
3. Разместите сайт на **Vercel / Netlify / Cloudflare Pages** (статика + serverless-функции).
4. Файл `api/lead.js` положите как `/api/lead.js` в проект (на Vercel это работает «из коробки»).
5. В настройках хостинга добавьте переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `TELEGRAM_CHAT_ID` — chat_id, куда слать заявки
6. В `script.js` сверху найдите `endpoint: ''` и поменяйте на `endpoint: '/api/lead'`.

Готово. Теперь заявки приходят в Telegram, а токен остаётся на сервере и в публичный код **не попадает**.

> На Netlify файл нужно положить в `netlify/functions/lead.js` и слегка адаптировать экспорт; на Cloudflare — в `functions/api/lead.js`. Логика та же.
